Вход администратора

Введите ключ администратора (переменная ADMIN_API_KEY в .env сервера). Ключ хранится только в этой вкладке.

Новый депозитарий

После создания будет показан API-ключ — передайте его депозитарию. Повторно ключ не показывается, его можно только перевыпустить.

Депозитарии

Депозитарий передаёт ключ в заголовке X-API-Key и видит только свои позиции и сделки.

НазваниеСтатусКлючПравил

Как работают правила

Каждое значение принадлежит одному депозитарию. Побеждает самое точное правило: точно → начинается с → содержит → все остальные. Значения, не попавшие ни под одно правило, не видит ни один депозитарий. Регистр букв не важен.

Покрытие данных

Все счета, тэги и классы, которые есть в базе, и кому они принадлежат по текущим правилам.
